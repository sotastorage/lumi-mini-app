Политика конфиденциальности

Hermes Agent · действует с 29 сентября 2026 года

Hermes Agent — персональный AI-ассистент, который по указанию владельца работает с сервисами Google. Эта политика объясняет, какие данные используются и как они защищаются.

Какие данные могут обрабатываться

  • письма Gmail и сведения, необходимые для чтения, поиска, подготовки и отправки писем;
  • файлы и папки Google Drive, документы Google Docs и таблицы Google Sheets;
  • события Google Calendar;
  • контакты Google в режиме чтения;
  • технические данные авторизации OAuth, необходимые для работы подключения.

Для чего используются данные

Данные используются только для выполнения команд владельца: поиска и обработки документов, работы с почтой, календарём, контактами и таблицами. Данные не продаются, не используются для рекламы и не передаются третьим лицам, кроме поставщиков инфраструктуры, необходимых для выполнения запрошенной операции.

Хранение и защита

Токены доступа и рабочие данные хранятся в закрытом серверном окружении с ограниченным доступом. Доступ предоставляется только компонентам ассистента, которым он необходим для выполнения задачи. Данные сохраняются только на срок, необходимый для работы ассистента и ведения его разрешённой владельцем памяти.

Управление доступом

Владелец может в любое время отключить доступ Hermes Agent в разделе безопасности Google Аккаунта: Сторонние приложения и сервисы. После отзыва доступа ассистент не сможет обращаться к данным Google до новой авторизации.
